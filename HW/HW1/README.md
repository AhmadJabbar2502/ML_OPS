This project contains two linear regression models made using the `sampregdata` dataset and scikit-learn. The first model uses `x4` as the only X variable and has an R² of 0.2750. The second and current model uses `x4` and `x2` as the two X variables and has an R² of 0.5136. The second model fits the data better than the first model because it explains more of the variation in `y`. Both models are saved in the `models` folder, with Model 1 saved as `model_v1.pkl` and Model 2 saved as `model_v2.pkl`. Git tags `v1.0-model-x4` and `v2.0-model-x4-x2` are used to keep both versions accessible.
